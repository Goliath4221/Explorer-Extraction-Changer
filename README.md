# Explorer-Extraction-Changer
Changes the extract button on file explorer to use 7-Zip or Winrar instead of normal extraction.
This can make the extraction process up to 5x faster.

## Supported Software
7-Zip
Winrar
Peazip
Bandizip
Nanazip

## Prerequisites
Have a supported app installed.
Thats it.

### This was mainly tested on 7-Zip, so there is no guarantee that other software will work perfectly. If it doesn't let me know and I will try to deploy a fix.
